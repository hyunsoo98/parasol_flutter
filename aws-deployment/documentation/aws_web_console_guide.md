# 🌐 AWS 웹 콘솔 단계별 설정 가이드

AWS 홈페이지에서 마우스 클릭으로만 모든 리소스를 생성하는 방법입니다.

---

## 1️⃣ AWS 콘솔 로그인 및 기본 설정

### 로그인
1. **브라우저에서 https://aws.amazon.com 접속**
2. **우측 상단 "콘솔에 로그인" 클릭**
3. **계정 정보 입력 후 로그인**
4. **우측 상단에서 "미국 서부(캘리포니아 북부)" 리전 선택** ⭐ 중요!

---

## 2️⃣ DynamoDB 테이블 생성

### 웹 콘솔 단계
1. **상단 검색창에 "DynamoDB" 입력 → 클릭**
2. **좌측 메뉴에서 "테이블" 클릭**
3. **주황색 "테이블 생성" 버튼 클릭**

### 테이블 설정 화면
4. **테이블 이름**: `eye-tracking-results` 입력
5. **파티션 키**: `analysis_id` 입력, 드롭다운에서 "String" 선택
6. **정렬 키**: 체크박스 해제 (비워둠)

### 테이블 설정 (아래로 스크롤)
7. **"테이블 설정" 섹션에서 "기본 설정 사용자 정의" 라디오 버튼 선택**
8. **"읽기/쓰기 용량 설정" 에서 "온디맨드" 라디오 버튼 선택**
9. **암호화는 기본값 유지**
10. **하단의 주황색 "테이블 생성" 버튼 클릭**
11. **생성 상태가 "생성 중..." → "활성"으로 변할 때까지 대기 (1-2분)**

---

## 3️⃣ S3 버킷 생성

### 웹 콘솔 단계
1. **상단 검색창에 "S3" 입력 → 클릭**
2. **주황색 "버킷 만들기" 버튼 클릭**

### 일반 구성
3. **버킷 이름**: `eye-tracking-videos-20241211` (날짜는 오늘 날짜로)
4. **AWS 리전**: "미국 서부(캘리포니아 북부) us-west-1" 선택되어 있는지 확인

### 객체 소유권 (기본값 유지)
5. **"ACL 비활성화됨(권장)" 라디오 버튼 선택됨 확인**

### 퍼블릭 액세스 차단 설정 (기본값 유지)
6. **4개 체크박스 모두 체크되어 있음 확인**

### 버킷 버전 관리 (기본값)
7. **"비활성화" 라디오 버튼 선택됨 확인**

### 태그 및 암호화 (기본값 유지)
8. **기본 설정 그대로 두기**
9. **하단의 주황색 "버킷 만들기" 버튼 클릭**

### CORS 설정 추가
10. **생성된 버킷 이름 클릭 (버킷 상세 페이지 이동)**
11. **"권한" 탭 클릭**
12. **페이지를 아래로 스크롤하여 "Cross-origin 리소스 공유(CORS)" 섹션 찾기**
13. **"편집" 버튼 클릭**
14. **텍스트 박스에 다음 내용 복사붙여넣기:**
```json
[
    {
        "AllowedHeaders": ["*"],
        "AllowedMethods": ["GET", "PUT", "POST", "DELETE"],
        "AllowedOrigins": ["*"],
        "ExposeHeaders": ["ETag"],
        "MaxAgeSeconds": 3000
    }
]
```
15. **주황색 "변경 사항 저장" 버튼 클릭**

---

## 4️⃣ SQS 큐 생성

### 웹 콘솔 단계
1. **상단 검색창에 "SQS" 입력 → 클릭**
2. **주황색 "큐 생성" 버튼 클릭**

### 큐 구성
3. **유형**: "표준" 라디오 버튼 선택 (기본값)
4. **이름**: `eye-tracking-queue` 입력

### 구성 설정 (기본값에서 일부 변경)
5. **"구성" 섹션을 펼치기** (화살표 클릭)
6. **가시성 제한 시간**: `960` 입력 (16분)
7. **메시지 보존 기간**: `1209600` 입력 (14일)
8. **수신 대기 시간**: `0` 그대로 유지
9. **최대 수신 횟수**: `3` 입력

### 액세스 정책 (기본값 유지)
10. **"액세스 정책" 섹션은 기본값 유지**

### 생성 완료
11. **하단의 주황색 "큐 생성" 버튼 클릭**
12. **큐 URL 복사해두기** (나중에 Lambda에서 사용)

---

## 5️⃣ Lambda Layer 생성 (선택사항)

### 웹 콘솔 단계
1. **상단 검색창에 "Lambda" 입력 → 클릭**
2. **좌측 메뉴에서 "레이어" 클릭**
3. **주황색 "레이어 생성" 버튼 클릭**

### 레이어 구성
4. **이름**: `eye-tracking-dependencies` 입력
5. **설명**: `OpenCV, MediaPipe, NumPy, Pandas for Eye Tracking` 입력
6. **코드 업로드 방법**: ".zip 파일 업로드" 라디오 버튼 선택
7. **"업로드" 버튼 클릭하여 미리 생성한 `eye_tracking_layer.zip` 파일 선택**
8. **호환 런타임**: "Python 3.9", "Python 3.10", "Python 3.11" 체크박스 선택
9. **주황색 "생성" 버튼 클릭**

---

## 6️⃣ Lambda 함수 생성 (3개)

### A. Upload 함수 생성

#### 기본 설정
1. **Lambda 대시보드에서 "함수" → "함수 생성" 클릭**
2. **"새로 작성" 라디오 버튼 선택**
3. **함수 이름**: `eye-tracking-upload` 입력
4. **런타임**: "Python 3.9" 선택
5. **아키텍처**: "x86_64" 선택

#### 실행 역할
6. **"기본 실행 역할 변경" 펼치기**
7. **"기존 역할 사용" 라디오 버튼 선택**
8. **기존 역할**: 드롭다운에서 적절한 역할 선택 (없으면 "새 역할 생성" 선택)
9. **주황색 "함수 생성" 버튼 클릭**

#### 함수 코드 업로드
10. **함수 상세 페이지에서 "코드" 탭 클릭**
11. **"업로드" 드롭다운 → ".zip 파일" 선택**
12. **`lambda_upload.zip` 파일 업로드**

#### 환경 변수 설정
13. **"구성" 탭 클릭**
14. **좌측 "환경 변수" 클릭**
15. **"편집" 버튼 클릭**
16. **"환경 변수 추가" 버튼을 3번 클릭하여 다음 변수들 입력:**
    - 키: `S3_BUCKET`, 값: `eye-tracking-videos-20241211` (본인 버킷명)
    - 키: `SQS_QUEUE_URL`, 값: `https://sqs.us-west-1.amazonaws.com/계정번호/eye-tracking-queue`
    - 키: `DYNAMODB_TABLE`, 값: `eye-tracking-results`
17. **"저장" 버튼 클릭**

#### 타임아웃 설정
18. **좌측 "일반 구성" 클릭**
19. **"편집" 버튼 클릭**
20. **제한 시간**: `2분 0초`로 변경
21. **메모리**: `512 MB`로 설정
22. **"저장" 버튼 클릭**

#### 레이어 연결 (선택사항)
23. **함수 상세 페이지 하단에서 "레이어" 섹션 찾기**
24. **"레이어 추가" 버튼 클릭**
25. **"사용자 지정 레이어" 라디오 버튼 선택**
26. **사용자 지정 레이어**: `eye-tracking-dependencies` 선택
27. **버전**: `1` 선택
28. **"추가" 버튼 클릭**

### B. Process 함수 생성

#### 동일한 방식으로 함수 생성
1. **함수 이름**: `eye-tracking-process`
2. **코드**: `lambda_process.zip` 업로드
3. **환경 변수**: Upload와 동일 (SQS_QUEUE_URL 제외)
4. **타임아웃**: `15분 0초`
5. **메모리**: `3008 MB` (최대)
6. **레이어**: 동일하게 추가

#### SQS 트리거 설정
7. **함수 상세 페이지에서 "구성" → "트리거" 클릭**
8. **"트리거 추가" 버튼 클릭**
9. **트리거 구성**: "SQS" 선택
10. **SQS 대기열**: `eye-tracking-queue` 선택
11. **배치 크기**: `1`
12. **"추가" 버튼 클릭**

### C. Status 함수 생성

#### 동일한 방식으로 함수 생성
1. **함수 이름**: `eye-tracking-status`
2. **코드**: `lambda_status.zip` 업로드
3. **환경 변수**: S3_BUCKET, DYNAMODB_TABLE만 설정
4. **타임아웃**: `30초`
5. **메모리**: `256 MB`
6. **레이어**: 필요 없음 (boto3만 사용)

## 7️⃣ API Gateway 생성

### REST API 생성
1. **상단 검색창에 "API Gateway" 입력 → 클릭**
2. **"API 생성" 버튼 클릭**
3. **"REST API" 카드에서 "구축" 버튼 클릭**

### API 설정
4. **"새 API" 라디오 버튼 선택**
5. **API 이름**: `EyeTrackingAPI` 입력
6. **설명**: `Eye Tracking Analysis API` 입력
7. **엔드포인트 유형**: "리전" 라디오 버튼 선택
8. **"API 생성" 버튼 클릭**

### 리소스 생성

#### A. /upload 리소스
1. **루트 리소스 "/" 선택**
2. **"작업" 드롭다운 → "리소스 생성" 클릭**
3. **리소스 이름**: `upload` 입력
4. **리소스 경로**: `/upload` 자동 입력됨
5. **"리소스 생성" 버튼 클릭**

#### B. POST 메서드 추가
6. **방금 생성한 `/upload` 리소스 선택**
7. **"작업" 드롭다운 → "메서드 생성" 클릭**
8. **드롭다운에서 "POST" 선택 → 체크 아이콘 클릭**

#### C. 통합 설정
9. **통합 유형**: "Lambda 함수" 라디오 버튼 선택**
10. **"Lambda 프록시 통합 사용" 체크박스 선택**
11. **Lambda 리전**: "us-west-1" 선택**
12. **Lambda 함수**: `eye-tracking-upload` 입력 (자동완성됨)**
13. **"저장" 버튼 클릭**
14. **권한 추가 확인창에서 "확인" 클릭**

#### D. CORS 활성화
15. **POST 메서드가 선택된 상태에서 "작업" → "CORS 활성화" 클릭**
16. **기본 설정 그대로 "CORS 활성화 및 기존 CORS 헤더 바꾸기" 클릭**
17. **확인창에서 "예, 기존 값 바꾸기" 클릭**

### /status 리소스 및 메서드 생성

#### A. /status 리소스
1. **루트 "/" 선택 → "작업" → "리소스 생성"**
2. **리소스 이름**: `status`
3. **"리소스 생성" 클릭**

#### B. GET 메서드 추가
4. **`/status` 선택 → "작업" → "메서드 생성" → "GET" 선택**
5. **통합 설정**: `eye-tracking-status` 함수 연결
6. **CORS 활성화**

#### C. {analysis_id} 리소스
7. **`/status` 리소스 선택 → "작업" → "리소스 생성"**
8. **리소스 이름**: `{analysis_id}` 입력
9. **"리소스 생성" 클릭**
10. **GET 메서드 추가 및 함수 연결**
11. **CORS 활성화**

### API 배포
1. **루트 "/" 선택 → "작업" → "API 배포" 클릭**
2. **배포 스테이지**: "[새 스테이지]" 선택**
3. **스테이지 이름**: `prod` 입력**
4. **"배포" 버튼 클릭**

### API URL 복사
5. **배포 완료 후 나타나는 "호출 URL" 복사**
6. **예: `https://abc123def.execute-api.us-west-1.amazonaws.com/prod`**

## 8️⃣ 최종 확인 및 테스트

### 생성된 리소스 확인
1. **DynamoDB**: `eye-tracking-results` 테이블 활성 상태
2. **S3**: `eye-tracking-videos-날짜` 버킷 생성됨
3. **SQS**: `eye-tracking-queue` 큐 사용 가능 상태
4. **Lambda**: 3개 함수 모두 배포됨
5. **API Gateway**: 배포 완료 및 URL 확인

### Flutter 앱 설정
1. **`lib/services/aws_async_eye_tracking_service.dart` 파일 열기**
2. **3번째 줄의 `_baseUrl` 을 복사한 API URL로 변경:**
```dart
static const String _baseUrl = 'https://복사한API주소.execute-api.us-west-1.amazonaws.com/prod';
```

### 간단한 테스트
1. **Lambda 콘솔에서 각 함수의 "테스트" 버튼으로 기본 동작 확인**
2. **API Gateway 콘솔에서 "테스트" 탭으로 엔드포인트 테스트**
